# Contributing to Ascension Realms — Pet System

Thank you for your interest in contributing! 🎮

## Ways to Contribute

- 🐛 **Bug reports** — Open an issue using the bug report template
- 💡 **Feature requests** — Share your ideas via feature request template
- 🐾 **New pets** — Add new pet designs with stats and sprites
- ⚔️ **Battle mechanics** — Improve combat AI or add new abilities
- 📱 **Mobile UX** — Improve touch controls and responsiveness
- 📝 **Documentation** — Improve README, game design docs, or code comments

## Development Workflow

1. Fork the repo and clone it locally
2. Create a branch: `git checkout -b feat/your-feature`
3. Make your changes in `index.html` or the `code/` modules
4. Test in multiple browsers (Chrome, Firefox, Safari, mobile)
5. Commit with a clear message: `git commit -m 'feat: add Crystalwing pet'`
6. Push and open a Pull Request

## Code Style

- Use `const`/`let`, no `var`
- Comment complex canvas math
- Keep pet stat values balanced (see `docs/GAME_DESIGN.md`)
- Test on both desktop and mobile before submitting

## Pet Submission Format

When adding a new pet, include:
- Name, type, base stats (HP, ATK, DEF, SPD)
- Special ability name + description
- Pixel art or SVG sprite (optional but appreciated)

Open a [Discussion](https://github.com/yourusername/ascension-realms-pet-system/discussions) and we'll help!
