## 🌟 About the Project

**Ascension Realms** is a fully browser-based open-world RPG featuring a rich pet selection and battle system. No frameworks, no build tools — just HTML5, Canvas 2D, and vanilla JavaScript.

### ✨ Features

| Feature | Description |
|---|---|
| 🐾 **Pet Selection** | Choose from multiple unique pets with different stats and abilities |
| ⚔️ **Real-Time Combat** | Fluid turn-based battle system with animations |
| 🌍 **Open World Map** | Explore a procedurally structured game world |
| 📱 **Mobile Ready** | Full touch support for mobile play |
| 🎨 **Sci-Fi HUD** | Immersive cyberpunk/sci-fi UI design using Orbitron & Rajdhani fonts |
| 🔊 **No Install Needed** | Open `index.html` in any modern browser and play |

## 🚀 Quick Start

### Option 1 — Play Online

👉 **https://yourusername.github.io/ascension-realms-pet-system/**

### Option 2 — Run Locally

```bash
# Clone the repository
git clone https://github.com/yourusername/ascension-realms-pet-system.git
cd ascension-realms-pet-system

# Just open index.html in your browser!
open index.html
# or
start index.html  # Windows
```

No Node.js, no npm, no build step required.

## 🛠️ Tech Stack

- **Rendering:** HTML5 Canvas 2D API
- **Language:** Vanilla JavaScript (ES6+)
- **Fonts:** Google Fonts (Orbitron, Rajdhani, JetBrains Mono)
- **Styling:** Pure CSS3 with custom properties
- **No frameworks, no bundlers, no dependencies**
